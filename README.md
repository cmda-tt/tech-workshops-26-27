## Omschrijving

Gedurende het vak geven de technische docenten een aantal workshops om aan alle studenten uit te leggen wat het belang is technisch data transformeren, structureren en real-time dynamische data ophalen vanuit een externe data API in plaats van statische data. Op dit moment staan er 3 workshops op de planning met verschillende thema's (zie topics), de onderwerpen van de workshops komen terug in de desbetreffende 'weekopdrachten' tijdens die week. We gebruiken Python en Jupyter notebooks waarmee je snel grote datasets kunt ophalen en snel kan plotten om te exploreren. We zien binnen deze minor deze technieken als 'tools' waarmee je wathands-on ervaring moet hebben en er in grote lijnen mee overweg en kan gebruiken. We verwachten niet dat je aan het einde de code door en door kent op het niveau van een data scientist.

## Doelen

Tijdens de workshops komen de volgende onderwerpen aanbod:

- Het opzetten van een Python en Jupyter notebooks omgeving
- Het kunnen herkennen van Data formaten en kunnen labelen
- Wat een API is en hoe de structuur van API's in elkaar ziten
- Hoe je om kan gaan met verschillende data formaten en structuren
- Met code data ophalen van een externe API en loggen
- In een Notebook die data formateren en graphs plotten
